# AgroLand — короткая внутренняя памятка (RU)

Полное описание на английском: `README.md`. Что нужно от команды: `docs/DEPLOY.md`.

* Запуск локально без оплаты (только для разработчиков): `python scripts/dev.py --unpaid` → http://127.0.0.1:8080. Красная плашка «UNPAID DEV MODE» обязательна; для демо жюри использовать только режим `masumi`.
* Тесты: `pytest gateway/tests -q` (23), `cd agent && npm test` (25).
* Что ещё НЕ сделано (нужны ваши доступы/разрешения): вход в Sokosumi (OAuth), ключ модели, платёжный сервис Masumi + кошелёк с тестовыми средствами, регистрация трёх агентов (необратима, тратит tADA), первый платный job и хэш транзакции, домен/TLS, запуск docker compose на сервере.
* Открытый вопрос: токен оплаты. Гайд по листингу Sokosumi требует tUSDM, а гайд пополнения кошельков пишет, что USDM на preprod нет. Уточнить у инженера Masumi до настройки кошельков.
* Секреты: в `geo-pooler.tar` лежал живой `.env` с seed-фразой кошелька. В проект он НЕ скопирован. Если этот кошелёк не одноразовый тестовый — считать скомпрометированным.
* Известный конфликт: README geo-pooler рекомендует Sokosumi CLI 1.1.0, т.к. 1.0.4 якобы вызывает удалённый маршрут; гайд хакатона требует 1.0.4. Сначала проверить 1.0.4.
